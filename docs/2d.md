# 2D 渲染器设计

## 屏幕2D

### 绘制顺序

每个渲染单元的 z-index 取自 `modelMatrix[3].z`。每帧收集渲染单元，使用 `std::sort` 按 z-index 从小到大排序后绘制，z-index 较大的单元后绘制。相同 z-index 的单元不保证绘制顺序。

UI 管线启用颜色混合，关闭深度测试和深度写入，重叠元素的合成结果由绘制顺序决定。材质绑定只在有序列表中相邻单元的材质发生变化时更新。

### GPU 资源和渲染

#### 描述符集

- binding 0: 静态字符 atlas
- binding 1: 动态字符 atlas
- binding 2: quad buffer的不定长数组

#### Quad 结构

- vec4 quadRect 左下角和右上角坐标
- vec4 uvRect 左下角和右上角uv
- vec4 color 颜色或其他浮点信息
- uvec4 info 整型信息
  - x: texture id

共占用4 * 4 * 4B = 64B 

#### Quad Manager

开辟若干大的buffer作为所有2D quad共有的存储空间

- 一份CPU存储quad的CPU状态
- 每个buffer固定包含512个quad，最多16个buffer，总容量8192个quad
- MAX_FRAMES_IN_FLIGHT 份 device buffer，每一帧从CPU buffer同步当前帧的buffer
- 每个buffer独立使用 updateCnt 计数，修改后设为 MAX_FRAMES_IN_FLIGHT，每次整体同步对应buffer后updateCnt -= 1
- 维护一个空闲列表，空闲列表记录quad buffer里的空闲槽位编号
  - 分配时从空闲列表里找空闲槽位，返回buffer编号和buffer内槽位编号组成的一个uint32_t
  - 不够分就开一个新的buffer和 MAX_FRAMES_IN_FLIGHT 个 device buffer
  - 回收时接受编号列表，放回空闲列表里
- 在描述符集里用 non uniform 维护 buffer描述符，有 MAX_FRAMES_IN_FLIGHT 份描述符集，同样用一个 updateCnt 控制更新

#### 2D Render Unit

- id：由 Renderer 分配的单元编号
- model matrix：渲染单元持有的矩阵副本，由 `UIComponent::OnTransformed` 同步，不保存 Transform 的地址
- quad ids：包含的所有 quad

渲染时，绑定顶点数组（所有quad id），设定 model 的 push constant 进行GPU实例渲染。不同unit之间不合批，每个unit独立产生一次draw call。

#### 2D Material State

`Layered2DRenderer` 通过 `Material*` 索引并持有 `Layered2DMaterialState`。使用同一材质的渲染单元共用一份状态：

- material：材质的 `shared_ptr`，保证材质在缓存期间有效
- pipeline：该材质在 2D 渲染中的图形管线
- commonDescriptorSet：材质纹理的描述符集；字体图集和 quad buffer 使用 Renderer 持有的逐帧描述符集

分配渲染单元时查找或创建材质状态，单元保存其非拥有指针。材质状态保留到 Renderer 的 Reset 或析构。`Renderer::Reset` 等待 GPU 工作完成后调用各 pass 的 Reset；2D Renderer 先清理单元，再释放材质状态、重置 quad ID 顶点缓冲池和单元 ID 分配器。

#### Layered 2D Renderer

用于半透明等需要混合的2D渲染，统一持有材质状态和渲染单元。单元通过 ID 索引存储在 `std::map` 中，每帧构造单元指针列表并按 z-index 排序，排序复杂度为 O(n log n)。变换更新直接写入单元的矩阵，下一次绘制使用更新后的 z-index。

支持以下操作：

- `AllocateUnit`：接受材质、model matrix 和 quad ids，分配并返回 `vke_ds::id32_t` 单元 ID，关联共享材质状态并构造渲染单元；quad 槽位由 UI 组件通过 Quad Manager 管理
- `DestroyUnit`：按 ID 销毁渲染单元，归还其 quad ID 顶点缓冲分配；ID 不存在时无操作
- `UpdateUnitQuadIDs`：更新实例 ID 列表并标记逐帧顶点缓冲待同步；ID 不存在时返回 `false`，否则返回 `true`

### UI 组件基类

一个entity对应一个，与 renderable object类似，使用entity对应的transform的model矩阵作为变换矩阵，z作为z-index

- id：由 Renderer 分配的id
- material：使用的材质
- 2D render unit

组件创建时向 Renderer 分配渲染单元，`OnTransformed` 同步单元的矩阵，`Unload` 销毁渲染单元并归还 quad 槽位。文本重建生成 quad 列表，再通过 `setGeometry` 更新单元的几何数据。
